# My Dream Home — Interactive 3D House Concept

A browser-based Three.js concept visualizer for a three-level Indian family home.

## House brief

- **Ground floor:** storage, a ventilated cattle shelter, feed / wash space, planting and potting area, and the main staircase.
- **First floor — 3BHK:** three bedrooms, living and dining area, kitchen, two bathrooms, and a front balcony.
- **Second floor — 2BHK:** two bedrooms, living area, kitchen, two bathrooms, and an upper terrace / balcony.

## Interactive features

- Explore the complete building or isolate any floor.
- Rotate, pan and zoom the 3D model.
- Switch to a top-down floor-plan view.
- Copy a plain-text version of the current design brief.
- Responsive layout for desktop, tablet and mobile.

## Technology

- HTML, CSS and JavaScript
- [Three.js](https://threejs.org/) and OrbitControls, loaded as browser ES modules from jsDelivr

## Run locally

Open `index.html` through a local static web server. ES module imports are not reliably supported when opening the file directly with `file://`.

## Important design note

This is an illustrative concept, not a structural, approval or construction drawing. The model uses placeholder proportions because the plot dimensions and local building constraints have not yet been supplied. A qualified local architect / structural engineer should validate room sizes, setbacks, foundations, columns, stair geometry, drainage, cattle ventilation, fire access and approvals before construction.
